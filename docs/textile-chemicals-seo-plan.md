## 3. On-Page SEO Best Practices

1. **Title Tags:**
   - Specific, containing product/category name + brand (`Om Sai Enterprise`).
   - Format: `<Product Name> | Om Sai Enterprise` (e.g. `Textile Wetting Agent | Om Sai Enterprise`).
2. **Meta Descriptions:**
   - 140–160 characters describing chemical function, process stage, and B2B sourcing in Surat, Gujarat.
3. **Structured Data:**
   - Valid JSON-LD `Product` schema with `Brand`, `Offer`, and seller identity.
   - BreadcrumbList schema on detail pages.
4. **Internal Linking:**
   - Contextual breadcrumb trail on all static child pages.
   - Cross-linking from Chemical Homepage (`chemicals/index.html`) and Main Catalogue (`chemicals/products.html`).
